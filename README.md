# Two Agents, One Hand-off

## Overview
A small Python program where two AI "agents" work in sequence. You enter a topic, the **ResearcherAgent** writes research notes about it, and those exact notes are handed to the **SummarizerAgent**, which turns them into exactly 3 bullet points. Each agent is a plain Python class that makes one call to Google's Gemini API. No agent frameworks are used.

## What is a Multi-Agent System?
A multi-agent system is several agents, each with its own role, that pass work to each other. Here:

`ResearcherAgent → SummarizerAgent`

The output of one agent becomes the input of the next. Two simple classes doing this already form a basic multi-agent system.

## Architecture
```text
User
 ↓
ResearcherAgent
 ↓
Research Notes
 ↓
HAND-OFF
 ↓
SummarizerAgent
 ↓
3-Bullet Summary
```

## How the Hand-off Works
The core of the project is two lines in `main.py`:

```python
research_notes = researcher.research(topic)
summary = summarizer.summarize(research_notes)
```

The value returned by the first agent is stored in `research_notes` and passed unchanged into the second agent. Nothing is hard-coded.

## What I Learned
- **Agent roles:** an agent is a class with a clear job, defined mainly by its prompt.
- **LLM calls:** each agent wraps one call to the Gemini API.
- **Agent-to-agent communication:** agents can communicate just by passing text.
- **Passing outputs:** one agent's return value becomes the next agent's input.
- **Frameworks:** tools like CrewAI or AutoGen can automate this wiring (roles, routing, retries) once the basic idea is understood.
